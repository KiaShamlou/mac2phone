# Introducing Mac2Phone

**Your screens. Closer together.**

Mac2Phone is an MIT-licensed, open-source project for sharing screens and controlling supported devices directly over a local network. It began with a touch-first way to use a Mac from an iPhone or iPad, and now includes desktop and Android implementations.

Discover nearby running apps, send a request, compare the verification code and accept before sharing. Control and Sound are separate opt-ins. The native Mac experience adds cursor-free Touch mode, while desktop-to-desktop sessions use WebRTC video with live quality controls.

**Windows and Android are Beta.** Expect rough edges and device-specific behavior. Linux is experimental. iPhone/iPad broadcasting is view-only, and Apple Watch is a companion remote through iPhone—not a standalone screen-sharing app. The native Mac host and desktop viewer are still separate while their integration is developed.
